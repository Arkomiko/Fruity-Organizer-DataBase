Ordnerstrukturen

Wähle eine Vorlage oder schreibe eine eigene aus diesen Teilen:

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Hersteller
  • Zweck
  • Hersteller \ Zweck
  • Zweck \ Hersteller
  • Format \ Hersteller
  • Format \ Zweck
  • Anfangsbuchstabe
  • USER \ Hersteller
  • USER \ Zweck \ Hersteller

Organisieren

  • Eine Kopie je Plugin: Gibt es ein Plugin in mehreren Formaten, wird eines kopiert. Die Reihenfolge steht in den Einstellungen.
  • Plugins mit Fehlern überspringen: Plugins, die FL Studio nicht scannen konnte, nicht kopieren.
  • Organisierte Plugins überspringen: Ein Plugin mit Stern liegt schon in Effects oder Generators und wird nicht erneut kopiert.
  • Organisierte neu anordnen: Plugins mit Stern in die Ordner der aktuellen Struktur verschieben. „Rückgängig“ nimmt das zurück.
  • Vorhandene Dateien überschreiben: Eine Datei ersetzen, die schon im Herstellerordner liegt.
  • Nur Plugins aus der Liste: Nur organisieren, was die Liste nach Filtern und Suche zeigt.
  • Aus dem Ordner New verschieben: Nach dem Einsortieren verschwindet das Plugin aus der Liste New in FL Studio. „Rückgängig“ holt es zurück.

Basiert auf FL Studio Automatic Plugin Organizer von Magabes und Mitwirkenden, unter der MIT-Lizenz.

Unabhängiges Projekt ohne Verbindung zu Image-Line. FL Studio ist eine Marke von Image-Line.
