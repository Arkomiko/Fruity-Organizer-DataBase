정리 옵션

  • 플러그인당 복사본 하나: 플러그인 형식이 여러 개면 하나만 복사합니다. 형식 순서는 설정에서 정합니다.
  • 오류 있는 플러그인 건너뛰기: FL Studio가 스캔하지 못한 플러그인은 복사하지 않습니다.
  • 이미 정리된 항목 건너뛰기: 별표가 있는 플러그인은 이미 Effects나 Generators에 있어 다시 복사하지 않습니다.
  • 정리된 항목 재배치: 별표 플러그인을 현재 구성의 폴더로 옮깁니다. 되돌리기 버튼으로 취소할 수 있습니다.
  • 기존 파일 덮어쓰기: 제조사 폴더에 이미 있는 파일을 바꿉니다.
  • 목록의 플러그인만: 필터와 검색 후 목록에 보이는 항목만 정리합니다.
  • New 폴더에서 옮기기: 정리하면 플러그인이 FL Studio의 New 목록에서 사라집니다. 실행 취소 버튼으로 되돌릴 수 있습니다.

Magabes와 기여자들의 FL Studio Automatic Plugin Organizer를 기반으로 하며 MIT 라이선스를 따릅니다.

독립 프로젝트이며 Image-Line과 관련이 없습니다. FL Studio는 Image-Line의 상표입니다.
