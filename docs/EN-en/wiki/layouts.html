Folder layouts

Pick a preset or write your own template from these parts:

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Vendor
  • Purpose
  • Vendor \ Purpose
  • Purpose \ Vendor
  • Format \ Vendor
  • Format \ Purpose
  • First letter
  • USER \ Vendor
  • USER \ Purpose \ Vendor

Organize options

  • One copy of each plugin: If a plugin comes in several formats, one is copied. The order of formats is set in Settings.
  • Skip plugins with errors: Do not copy plugins FL Studio failed to scan.
  • Skip plugins already organized: A starred plugin is already in Effects or Generators, so it is not copied again.
  • Rearrange organized plugins: Move starred plugins into the folders of the current layout. The Undo button reverts this.
  • Overwrite existing files: Replace a file already present in the vendor folder.
  • Only plugins in the list: Organize only what the list shows after filters and search.
  • Move out of the New folder: Once organized, a plugin leaves FL Studio's New list. The Undo button brings it back.
