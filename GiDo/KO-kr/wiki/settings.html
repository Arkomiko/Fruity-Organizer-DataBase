설정

일반

  • 언어
  • 시작할 때
  • 닫기 버튼
  • 플러그인 두 번 클릭
  • 항상 위
  • FL Studio 플러그인 데이터베이스

배치

  • 폴더 구성
  • 용도 폴더 언어
  • 폴더 이름에서 LLC, GmbH, Inc. 제거
  • New 폴더에서 옮기기
  • 복사본 하나일 때의 형식 순서

제조사

  • 목록과 폴더의 제조사 이름을 바꿉니다. 예: Direct를 MiniMeters로.

규칙

  • 처음 일치한 규칙이 자동 판별보다 우선합니다. 조건에는 정규식을 쓸 수 있습니다.

백업

  • 변경할 때마다 먼저 백업
  • 보관할 백업 수
  • 확인 요청

모양

  • 색상 테마
  • 인터페이스 배율
  • 글꼴
  • 글꼴 크기
  • 부드러운 전환과 애니메이션
  • 목록 열

키

  • 행을 두 번 클릭하면 다른 단축키를 지정합니다.

데이터

  • 활동 로그
  • 파일로 내보내기
  • 파일에서 가져오기
  • 업데이트 확인
