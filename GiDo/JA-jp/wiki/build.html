ソースからビルド

Windows と Python 3.13 が必要です。本体は標準ライブラリのみを使用します。

./build.ps1

Magabes と貢献者による FL Studio Automatic Plugin Organizer をベースにしています（MIT ライセンス）。

独立したプロジェクトであり、Image-Line とは無関係です。FL Studio は Image-Line の商標です。
