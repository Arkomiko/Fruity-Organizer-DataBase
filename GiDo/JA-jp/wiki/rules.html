独自ルール

各プラグインの用途を判定：リバーブ、EQ、ダイナミクス、シンセなど全 22 種類

「設定」タブまたは FODB.json でルールを追加し、正規表現で名前やメーカーごとに用途を指定できます：

"purpose_rules": [
  { "purpose": "drums", "name": "kick|808" },
  { "purpose": "vocal", "vendor": "antares" }
]

最初に一致したルールが自動判定より優先されます。条件には正規表現を使えます。
