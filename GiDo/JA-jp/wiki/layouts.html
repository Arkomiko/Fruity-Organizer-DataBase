フォルダー構成

プリセットを選ぶか、次の要素で独自のテンプレートを書けます：

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • メーカー
  • 用途
  • メーカー \ 用途
  • 用途 \ メーカー
  • 形式 \ メーカー
  • 形式 \ 用途
  • 頭文字
  • USER \ メーカー
  • USER \ 用途 \ メーカー

整理オプション

  • プラグインごとに 1 コピー: 複数の形式がある場合は 1 つだけコピーします。形式の順序は設定で指定します。
  • エラーのあるプラグインを除外: FL Studio がスキャンできなかったプラグインはコピーしません。
  • 整理済みを除外: 星印のプラグインは Effects か Generators にあるため再コピーしません。
  • 整理済みを再配置: 星印のプラグインを現在の構成のフォルダーへ移動します。「元に戻す」で取り消せます。
  • 既存ファイルを上書き: メーカーフォルダーにある同名ファイルを置き換えます。
  • 一覧のプラグインのみ: フィルターと検索後の一覧に表示されたものだけを整理します。
  • New フォルダーから移動: 整理すると FL Studio の New 一覧から消えます。「元に戻す」で戻せます。
