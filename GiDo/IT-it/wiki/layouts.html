Disposizioni delle cartelle

Scegli un modello o scrivine uno tuo con queste parti:

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Produttore
  • Funzione
  • Produttore \ Funzione
  • Funzione \ Produttore
  • Formato \ Produttore
  • Formato \ Funzione
  • Prima lettera
  • USER \ Produttore
  • USER \ Funzione \ Produttore

Opzioni di organizzazione

  • Una copia per plugin: Se un plugin esiste in più formati, ne viene copiato uno. L'ordine si imposta nelle Impostazioni.
  • Salta i plugin con errori: Non copiare i plugin che FL Studio non ha potuto analizzare.
  • Salta quelli già organizzati: Un plugin con la stella è già in Effects o Generators e non viene ricopiato.
  • Riordina gli organizzati: Sposta i plugin con la stella nelle cartelle della disposizione attuale. Annulla ripristina.
  • Sovrascrivi i file esistenti: Sostituisci un file già presente nella cartella del produttore.
  • Solo plugin in elenco: Organizza solo ciò che l'elenco mostra dopo filtri e ricerca.
  • Sposta dalla cartella New: Una volta organizzato, il plugin esce dall'elenco New di FL Studio. Il pulsante Annulla lo riporta indietro.
