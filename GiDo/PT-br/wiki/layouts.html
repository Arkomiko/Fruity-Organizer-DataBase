Layouts de pastas

Escolha uma predefinição ou escreva seu modelo com estas partes:

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Fabricante
  • Finalidade
  • Fabricante \ Finalidade
  • Finalidade \ Fabricante
  • Formato \ Fabricante
  • Formato \ Finalidade
  • Primeira letra
  • USER \ Fabricante
  • USER \ Finalidade \ Fabricante

Opções de organização

  • Uma cópia por plugin: Se um plugin existir em vários formatos, um é copiado. A ordem é definida nas Configurações.
  • Ignorar plugins com erro: Não copiar plugins que o FL Studio não conseguiu verificar.
  • Ignorar já organizados: Um plugin com estrela já está em Effects ou Generators e não é copiado de novo.
  • Reorganizar os organizados: Mover plugins com estrela para as pastas do layout atual. O botão Desfazer reverte.
  • Substituir arquivos existentes: Substituir um arquivo que já esteja na pasta do fabricante.
  • Só plugins da lista: Organizar só o que a lista mostra após filtros e busca.
  • Mover da pasta New: Depois de organizado, o plugin sai da lista New do FL Studio. O botão Desfazer o traz de volta.
