Modlar

İsteğe bağlı modlar: daha geniş eklenti listesi, açık katalog, sizden öğrenen ayrıntılı kullanımlar, önizleme ağacı ve durum şeritleri. Ayarlar, Veri bölümünden açılır.

Advenced purpose rules (experimentally)

optimization

A larger list of popular plugins (302 names: Serum, Kontakt, FabFilter and more), so their purpose is detected without manual edits. Add your own lines to rules.json.

Improving the algorithm for Determining Purpose (experimentally)

optimization

Adds finer purposes: saturation, transient shaper, algorithmic and convolution reverb, compressor, limiter. Learns from you: when you set a purpose by hand or move a plugin to a folder named after a purpose, other plugins of the same vendor and family get it automatically. New purposes are named in English and Russian.

Other Integration BD (experimentally)

optimization

Fills in a missing vendor, purpose and search tags by plugin name from an open catalog. The catalog ships with the mod. The update button downloads a fresh copy from the project's GitHub and sends nothing about your plugins.

Preview Tree

UX/UI

Replaces the preview list with a folder tree. Drag a plugin to another folder and the structure changes at once. Clicking a folder collapses it. Only the folders of this run are shown, and Effects cannot be moved to Generators.

Status Indicators (experimentally)

UX/UI

Adds a color stripe to the list rows. Green: already organized. Gold: in a folder named Favorites. Blue: new and not organized yet (in the New folder or installed in the last 14 days).

Modifikasyonlar

Mod, index.json ve kod gerekiyorsa mod.py içeren bir klasördür. Kendi modlarınızı FODB.exe yanındaki mods klasörüne koyun. Modlar programın parçası olarak çalışır, yalnızca güvendiklerinizi kurun.

# mods/My mod/index.json
{"name": "My mod", "type": "optimization", "version": "1.0", "author": "Me", "entry": "mod.py",
 "description": {"EN-en": "What it does"}}

# mods/My mod/mod.py
def activate(api):
    api.add_purpose_hook(lambda plugin: ["reverb"] if "hall" in plugin.name.casefold() else None)
