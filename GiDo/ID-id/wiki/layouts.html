Tata letak folder

Pilih prasetel atau tulis templat sendiri dari bagian berikut:

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Vendor
  • Kegunaan
  • Vendor \ Kegunaan
  • Kegunaan \ Vendor
  • Format \ Vendor
  • Format \ Kegunaan
  • Huruf pertama
  • USER \ Vendor
  • USER \ Kegunaan \ Vendor

Opsi penataan

  • Satu salinan per plugin: Jika plugin punya beberapa format, satu yang disalin. Urutan format diatur di Pengaturan.
  • Lewati plugin bergalat: Jangan salin plugin yang gagal dipindai FL Studio.
  • Lewati yang sudah tertata: Plugin berbintang sudah ada di Effects atau Generators dan tidak disalin lagi.
  • Tata ulang yang tertata: Pindahkan plugin berbintang ke folder tata letak saat ini. Tombol Urungkan membatalkannya.
  • Timpa berkas yang ada: Ganti berkas yang sudah ada di folder vendor.
  • Hanya plugin dalam daftar: Hanya atur yang tampil di daftar setelah filter dan pencarian.
  • Pindahkan dari folder New: Setelah ditata, plugin keluar dari daftar New di FL Studio. Tombol Urungkan mengembalikannya.
