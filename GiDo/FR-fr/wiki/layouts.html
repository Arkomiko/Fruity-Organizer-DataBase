Dispositions de dossiers

Choisissez un préréglage ou écrivez votre modèle avec ces éléments :

{vendor}  {purpose}  {format}  {bits}  {letter}  {kind}

{vendor}\{purpose}
{purpose}\{vendor}
USER\{format}\{vendor}
  • Éditeur
  • Usage
  • Éditeur \ Usage
  • Usage \ Éditeur
  • Format \ Éditeur
  • Format \ Usage
  • Première lettre
  • USER \ Éditeur
  • USER \ Usage \ Éditeur

Options d'organisation

  • Une copie par plugin: Si un plugin existe en plusieurs formats, un seul est copié. L'ordre se règle dans les paramètres.
  • Ignorer les plugins en erreur: Ne pas copier les plugins que FL Studio n'a pas pu analyser.
  • Ignorer les plugins organisés: Un plugin étoilé est déjà dans Effects ou Generators : il n'est pas recopié.
  • Réarranger les organisés: Déplacer les plugins étoilés vers les dossiers de la disposition actuelle. Annuler rétablit tout.
  • Écraser les fichiers existants: Remplacer un fichier déjà présent dans le dossier de l'éditeur.
  • Seulement les plugins listés: Organiser seulement ce que montre la liste après filtres et recherche.
  • Déplacer depuis le dossier New: Une fois rangé, le plugin quitte la liste New de FL Studio. Le bouton Annuler le ramène.
